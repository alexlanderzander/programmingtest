## Featured project: AssetNode

[**AssetNode**](https://github.com/asset-node-com/asset-node.com) is a source-available IT asset-management platform from Elixio. Its stack combines **Vue 3, TypeScript, Fastify, and MongoDB**.

- Hardware inventory, software licences, employee assignments, and lifecycle tracking.
- A visual workflow engine with branching, human-review pauses, and execution history.
- MDM integrations, including an Intune connector with OAuth, pagination, and rate-limit handling.
- MCP tools that let AI assistants query and work with asset-management data.

[Product website](https://asset-node.com) · [Workflow engine](https://github.com/asset-node-com/asset-node.com/blob/main/src/server/services/workflowEngine.ts) · [Intune integration](https://github.com/asset-node-com/asset-node.com/blob/main/src/server/services/syncIntune.ts) · [MCP implementation](https://github.com/asset-node-com/asset-node.com/blob/main/src/mcp/server.ts)

AssetNode uses the Sustainable Use License; it is **source-available / fair-code**, with separate terms for enterprise components.
